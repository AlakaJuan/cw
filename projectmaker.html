Google Apps Script (GAS) 後端設定步驟

1. 開啟您的目標 Google Sheet，點選選單 **擴充功能 (Extensions) ➔ Apps Script**。

2. 刪除原本所有程式碼，將下方這段代碼 **完全複製並貼上**：

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getActiveSheet();
    
    // 如果是新工作表，建立標頭
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "專案名稱", "PM負責人", "PM Email", "專案開始日", 
        "工項類別", "工項名稱", "工項負責人", "相依項目", "工天 (Days)", "預計開始日", "預計完成日", "提交時間"
      ]);
      sheet.getRange(1, 1, 1, 12).setFontWeight("bold").setBackground("#0d9488").setFontColor("#ffffff");
    }
    
    var timestamp = new Date().toLocaleString("zh-TW", { timeZone: "Asia/Taipei" });
    
    // 寫入資料列
    data.tasks.forEach(function(task) {
      sheet.appendRow([
        data.projectName,
        data.pmName,
        data.pmEmail,
        data.startDate,
        task.type,
        task.name,
        task.assignee || data.pmName,
        task.dependencyName || "無",
        task.duration,
        task.startDate,
        task.endDate,
        timestamp
      ]);
    });
    
    return ContentService.createTextOutput(JSON.stringify({ "status": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

3. 點擊右上角 **部署 (Deploy) ➔ 新增部署 (New deployment)**。

4. 種類選擇 **Web 應用程式 (Web app)**，設定為：

  • 執行身份 (Execute as): **我 (Me)**
  • 誰有存取權限 (Who has access): **所有人 (Anyone)** (極重要！選錯會無法寫入)

5. 點擊部署並複製產生的 **Web App URL**（網址必須以 `/exec` 結尾），貼回本工具即可！

沒收到資料？排查 3 大常見原因：

  1. 填錯 URL：請確認輸入框貼的是 GAS 部署出來的 Web App 網址（以 /exec 結尾），而不是 Google Sheet 試算表本體的網址！
  2. 權限未設為所有人：「誰有存取權限」務必選 Anyone (所有人)。
  3. 修改程式碼未發布新版本：每次修改 GAS 程式碼後，必須點選「管理部署 ➔ 編輯 ➔ 選擇『建立新版本』」才會生效！

首次授權出現「Google hasn't verified this app」警告？

這是 Google 對個人自訂 Apps Script 的標準保護機制，請依序點擊：

  1. 點擊左下角／下方的 Advanced（進階）
  2. 點擊展開後的 Go to [專案名稱] (unsafe)（前往專案）
  3. 滑到最下方點擊 Allow（允許） 即可順利授權！

如何在 Google Sheet 中產生原生互動式甘特圖？

當資料成功同步寫入 Google Sheet 後，您可以：

  1. 選取表單資料範圍（包含第 1 列標頭）
  2. 點選 Google Sheet 上方選單 **「插入 (Insert)」➔「時間軸 (Timeline)」**
  3. 對應「開始日期」與「結束日期」，即可一鍵生成原生的互動甘特圖！
